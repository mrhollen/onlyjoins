SELECT u.username, o.order_date, p.product_name FROM users u INNER JOIN orders o ON u.id = o.user_id LEFT JOIN ( SELECT order_id, product_name FROM order_items WHERE quantity > 10 ) p ON o.id = p.order_id WHERE o.total_amount > 1000 ORDER BY o.order_date DESC;

SPICY INNER + LEFT JOIN

This join is hotter than a pepperoni pizza in July! It combines users with their high-value orders and only shows products with quantities over 10. Don't try this at home unless you're ready for some heat!

WITH recent_customers AS ( SELECT id, name FROM customers WHERE last_order_date > DATE_SUB(CURDATE(), INTERVAL 1 MONTH) ) SELECT rc.name AS customer_name, o.order_date, o.total_amount FROM recent_customers rc RIGHT JOIN orders o ON rc.id = o.customer_id WHERE o.shipping_status = 'delivered';

HOT RIGHT JOIN with CTE

This join is like a warm embrace from your database. It uses a Common Table Expression (CTE) to find recent customers and joins them with delivered orders. Warning: May cause database performance issues if not used responsibly!

SELECT e.employee_name, d.department_name, COUNT(p.project_id) AS project_count FROM employees e FULL OUTER JOIN departments d ON e.department_id = d.id LEFT JOIN projects p ON d.id = p.department_id GROUP BY e.employee_name, d.department_name HAVING project_count > 5;

FULL OUTER JOIN with GROUP BY

This join is a real showstopper! It combines employees and departments, even if they don't have matching records, and counts their projects. Only shows departments with over 5 projects. Warning: This one might blow your mind!

SELECT a.actor_name, m.movie_title, r.rating FROM actors a CROSS JOIN movies m LEFT JOIN ( SELECT movie_id, AVG(rating) AS rating FROM reviews GROUP BY movie_id ) r ON m.id = r.movie_id WHERE a.age > 30 ORDER BY r.rating DESC;

CROSS JOIN with AVERAGE RATINGS

This join is a real crowd-pleaser! It combines actors over 30 with all movies and their average ratings. Warning: This join might make your database cry if not optimized properly!
